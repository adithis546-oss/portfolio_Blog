# Adithi's Personal Portfolio

A one-page personal portfolio website created for GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository (for example, `adithi-portfolio`).
2. Upload `index.html`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.
7. Before publishing, replace `YOUR_GITHUB_LINK` and `YOUR_CONTACT_LINK` in `index.html` with your actual links.

No external libraries are required.
